# 魔幻赛马 · Horse Racing Web

**魔幻赛马** 的现代 Web 复刻版 —— 用原生 Web 技术重写经典 Qt 单机赛马游戏，
**像素级复用原作美术**，并修复了原作与初版 Web 版中的若干缺陷。

> 原作仓库：[github.com/lbbit/HR](https://github.com/lbbit/HR)（Qt Widgets 桌面单机游戏）
> 复刻仓库：[github.com/lbbit/HR_web](https://github.com/lbbit/HR_web)

---

## 玩法

键盘节奏竞速。每局共 **20 组** 按键，每组限时 **2 秒**，开局 3 秒倒计时。
屏幕下方会依次给出 6 个按键提示，你在限定时间内按出对应键即可前进：

- **简单模式**：按提示依次敲出 `↑ ↓ ← →` 方向键。
- **困难模式**：按提示依次敲出 `A–Z` 字母键。

单组得分公式与原作完全一致：

```
单组得分 = (80 · t² − 400 · t + 680) × 正确数 / 6
（t 为该组用时，单位秒，上限 2.0）
```

得分转化为赛马前进距离（`距离 = 得分 / 8`），**总分高于对手即获胜**。
每局结算后有机会解锁新马，集齐 20 匹达成传说成就。

### 操作

| 按键 | 作用 |
| --- | --- |
| `↑ ↓ ← →` | 简单模式输入 |
| `A–Z` | 困难模式输入 |
| `空格` | 暂停 / 继续比赛 |
| `Esc` | 比赛中立即退出，返回选关界面 |
| 界面左上「暂停」 | 打开暂停菜单（继续 / 退到选关） |

## 像素风复刻

本版**不是**重绘风格，而是**原样复用**原作手绘的像素素材：

- **13 个界面** 各自的原作像素背景图（`BG0`–`BG13`、`BG20` 对话框、赛道 `BG9_0`–`BG9_2`）
  直接作为界面底层，原作画好的标题、边框、纹理一像素不改。
- **按钮与文字标签**沿用原作 PNG。原作已把中文像素字**烘焙**进图里（原工程无字体文件），
  因此静态 UI 文字天然是像素风；按钮保留 `_W`/`_P`/`_C`（常态/按下/悬停）三态贴图。
- **马匹**为原作 120×90 的 `STAND`/`RUN1`/`RUN2` 帧序列；**按键图块**是原作透明箭头，
  叠在 CSS 绘制的米色圆角方块上，正确变绿、错误变红。
- **整屏等比缩放**：每个界面按原作分辨率建一个固定尺寸舞台
  （竖屏 `450×600`、比赛 `1000×622`、结算 `740×480`），整体 `transform: scale()` 适配窗口，
  配 `image-rendering: pixelated` 保证放大后依然是硬边像素，不糊不插值。
- **动态中文**（用户名、分数、日志）用 **Zpix 最像素字体**（CDN 引入，含等宽回退），
  与原作像素字风格统一。

素材体积：原作 330 个文件约 21 MB → **314 个无损 WebP 共 0.81 MB**
（`ffmpeg -c:v libwebp -lossless 1`，已逐张解码回环校验为像素完全一致）。

## 本次修复的问题

| # | 问题 | 根因 | 处理 |
| --- | --- | --- | --- |
| 1 | 首界面文字重叠 | 旧版用绝对定位把文字压在空背景上，彼此盖住 | 改为直接渲染原作 `BG0` 背景图（画好的标题已在图内），只在其上按原作坐标叠加按钮 |
| 2 | 比赛中无法提前退出 | 比赛界面没有任何退出入口 | 新增「暂停」按钮 + `空格` 暂停菜单（继续 / 退到选关），`Esc` 一键退出 |
| 3 | 比赛画面渲染异常 | ① `game.js` 的 `_endGroup()` 误用 `this.badge`（应为 `this.r.badge`），**第一组结束即抛异常，比赛永久卡死**；② 旧版 `assets.js` 的 `img()` 返回的是 Promise 而非已加载的 `Image`，`drawImage(promise)` 抛错导致整帧空白 | 修正 ref 取值；`img()` 改回返回已解析的 `HTMLImageElement`；比赛改由 DOM 渲染，与原作 QLabel 布局一一对应 |
| 4 | 未复刻像素风界面 | 旧版是自绘的暗色霓虹主题 | 全量重建为原作像素素材 + 固定分辨率舞台 + 最近邻缩放 + 像素字体（见上节） |

顺带修掉的其他缺陷：

- **`空格` 恢复比赛后暂停弹窗不关闭** —— `onResumeClose` 回调从未接线，现已接上。
- **选关界面首次进入时对手名与马匹计数为空白** —— 缺少 `onEnter` 钩子，从未初始化绘制。
- **排行榜数据结构不合法** —— 在空数组上做插入位移会产生稀疏数组，持久化成 `null` 洞；
  现改为与原作 `RankC rankE[5]` 一致的固定 5 槽表，并在读取时自动修复旧存档。
- **传说马 #19 骑乘时马匹消失** —— 原作只画了 `HORSE19_STAND`，没有 `RUN1/RUN2`，
  原作会渲染成空白 pixmap，Web 版则会产生 404。现让 #19 的跑动帧优雅回退到 `STAND`。
- **用户中心头像按钮未做登录态保护**，未登录时点击会抛 `TypeError`，现加了守卫。

## 特性

- **原生 ES Module**，无框架、无构建步骤、无依赖，直接由静态服务器托管即可。
- **零外部运行时依赖**：唯一外链是像素中文字体（jsDelivr CDN），其余全部本地。
- **程序化音频**（Web Audio API）：3 首可切换的电子/芯片风 BGM（霓虹疾驰 / 合成德比 / 像素冲刺）
  \+ 动态音效（按键对错、倒计时、马蹄、胜负、解锁），零音频文件，取代原作约 1.1 MB 的 WAV。
- **完整进度系统**：注册/登录、改名改密、简单/困难双榜（Top 5）、20 匹马收集、
  累计局数/时长/路程、最高分与最高排名、管理员用户管理。
- **本地存档**：`localStorage`（键 `hrweb_save_v2`），无需后端。
- 首次打开会自动预置演示账号：`admin / admin`（管理员）与 `lbb / 1234`。

## 运行

纯静态站点，任意静态服务器即可：

```bash
python -m http.server 8080
# 浏览器打开 http://localhost:8080
```

> `file://` 直接打开 `index.html` 会因 ES Module 的 CORS 限制失败，请用本地服务器。

## 与原作的对照

| 维度 | 原作 (Qt) | 复刻 (Web) |
| --- | --- | --- |
| 技术栈 | Qt Widgets (C++) | 原生 ES Module + DOM 渲染 + Web Audio |
| 美术 | 手绘像素 PNG | **同一批**像素图，无损 WebP（体积降至 4%） |
| 字体 | 像素字烘焙进 PNG | 静态 UI 沿用烘焙图，动态文字用 Zpix 像素字体 |
| 缩放 | 固定窗口（472×622 / 1020×642） | 固定分辨率舞台 + 等比缩放，任意屏幕自适应 |
| 音频 | 5 段约 1.1 MB WAV | 程序化合成 3 首 BGM + 音效（零音频文件） |
| 对手 | 随机三档技能的虚拟对手 | 同一套技能区间与出招公式 |
| 存档 | 本地二进制文件 | localStorage |
| 排行榜 | `RankC rankE[5]` 固定 5 槽，**不按用户名去重** | 同（忠实还原） |
| 初始马匹 | 注册即送 3 匹（#0 #1 #2） | 同 |
| 传说马 | 集齐 #0–#18 后自动解锁 #19 | 同（并修复其跑动帧缺失导致的空白） |
| 分发 | Inno Setup 安装包 | 静态站点 / 任意托管 |

## 验证

仓库自带一套无头回归测试，无需浏览器：它模拟 DOM / Web Audio / `requestAnimationFrame`，
加载**真实的** ES Module 并驱动完整游戏流程。覆盖：13 个界面的进入与交互、
注册/登录/改名/改密、管理员删号、完整 20 局比赛、暂停/继续/退出、`Esc` 退出、
排行榜与 20 匹马解锁（含传说马 #19）、音频引擎全部分支、
以及 314 个素材的磁盘存在性、大小写敏感路径、和可选的 HTTP 200 + MIME 校验。

```bash
# 主回归测试（约 40s，随机数已固定，结果可复现）
node test/harness.mjs

# 素材完整性（可选：加本地服务器地址则额外校验 HTTP 状态与 MIME）
python -m http.server 8080 &
node test/assets.mjs http://127.0.0.1:8080
```
