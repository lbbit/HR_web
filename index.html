      游戏规则

      • 每局共 20 组 按键，每组限时 2 秒，开局有 3 秒倒计时。
      • 简单模式：按屏幕提示依次按下 ↑ ↓ ← → 方向键。
      • 困难模式：按提示依次敲出 A–Z 字母键，组合更丰富。
      • 按键越准、越快，得分越高。单组得分 = (80·t² − 400·t + 680) × 正确数 / 6（t 为该组用时）。
      • 得分转化为赛马前进距离，总分高于对手即获胜。
      • 每局结算后有机会 解锁新马，集齐 20 匹达成传说成就。
      • 空格键可随时 暂停 / 继续。背景音乐与音效可在设置中开关。

      关于

      本作是 魔幻赛马（HorseRacing） 的现代 Web 复刻版。

      原作是基于 Qt Widgets 的桌面单机游戏（作者大学时期作品），含登录注册、赛马玩法、排行榜、抽奖成长等。

      复刻版采用 HTML5 Canvas + Web Audio + 原生 ES Module 重写：更流畅的 60fps 动画、粒子特效、程序化生成的现代背景音乐与音效（替换原音频），并用原工程的马匹精灵、赛道背景与按键素材。

      原仓库：github.com/lbbit/HR　·　复刻仓库：github.com/lbbit/HR_web
